# Audio asset inventory

No audio assets or recipes ship in this scaffold. Step 6 must establish original or licensed material
and listening acceptance before expanding the catalog. No extracted Endel assets are permitted.

Every future asset must record: relative path, SHA-256, creator, license/ownership evidence, permitted
distribution, sample rate, channel layout, loudness, key where applicable, loop boundaries and allowed
pitch/tempo treatment. Recipes require stable mode IDs and explicit versions. Do not add catalog tiles
that imply playback before accepted audio exists.
